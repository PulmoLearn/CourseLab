Copy a published course

Copy the exact current published lesson content to another instructor account. The recipient gets a new, independent course with a new enrollment code.

Signed in as Checking account…

1. Export from the original instructor account

Select the finished published course. Download its private course-transfer file and send it securely to the receiving instructor.

Only the published course snapshot is exported—not drafts, students, enrollments, grades, test attempts, research submissions, or participant mappings.

2. Import into the receiving instructor account

The receiving instructor signs in to their own account and uploads the exported JSON file here. This creates a separate published course.

A new enrollment code will be generated. Existing learner codes from the source course won't work for the copy. Keep the export file private because it contains all course content and assessment answer keys.

Course copy created

The course is published under the currently signed-in instructor account with a fresh enrollment code.
